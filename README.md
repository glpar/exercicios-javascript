# Exercícios de JavaScript

Coleção de exercícios introdutórios para praticar lógica de programação, funções, objetos, arrays, estruturas condicionais e manipulação de strings em JavaScript.

## Exercícios

- `teste1`: converte uma nota numérica para os conceitos A, B, C, D ou F;
- `teste2`: calcula receitas, despesas e o saldo de uma família;
- `teste3`: converte temperaturas entre Celsius e Fahrenheit;
- `teste4`: pesquisa e contabiliza livros, autores e categorias.

## Tecnologias

HTML e JavaScript puro, sem dependências externas.

## Como instalar

Não há instalação de pacotes. Basta clonar o repositório:

```bash
git clone https://github.com/glpar/exercicios-javascript.git
cd exercicios-javascript
```

## Como executar

Abra o arquivo `index.html` da pasta desejada no navegador. Os resultados são exibidos no console do navegador.

Para abrir o console:

1. pressione `F12` ou use as ferramentas de desenvolvedor;
2. selecione a aba **Console**;
3. recarregue a página para executar o script.

Você pode alterar os valores no final de cada arquivo `script.js` para testar novas entradas.
